# lc2text_replacer.exe

## usage

LC2Text_Replacer v.1.0 - Ersetzt Text in Dateien
  --search <SEARCH>
  --replace <REPLACE>
  
### options

  -s, --search <SEARCH>    Der zu suchende Text
  -r, --replace <REPLACE>  Der Text, der stattdessen eingefügt werden soll
  -d, --dir <DIR>          Das Zielverzeichnis, das durchsucht werden soll [default: .]
  -h, --help               Print help
  -V, --version            Print version  

### requirements

requires a image as source
